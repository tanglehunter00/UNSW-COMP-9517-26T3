# Lab 2
Open `Lab2.ipynb` in Jupyter and run all cells from this directory. Install `requirements.txt` if needed. The notebook contains code, displayed results and explanations for the supplied pair and an additional pair configured through `PERSONAL_PATHS`.

`crop_pair.py` is a separate utility that creates a 1000x1000 left-edge p1 crop and a fully valid right-side p2 crop after 5 degrees of clockwise rotation, in the input image directory. Run `python crop_pair.py` to use the default input, or pass an input path and optionally `--output-dir` or `--angle`. Cropping code is not included in the notebook.

All notebook code cells have been executed. `results/` contains exported panoramas and inlier visualizations. No assignment submission has been performed.
