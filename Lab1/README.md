# Lab 1

Open Lab1.ipynb in Jupyter or VS Code. All code cells have been executed; figures, measurements, answers, and validation results are embedded.

To rerun, install the packages listed in requirements.txt, keep COMP9517_26T3_Lab1_Images beside the notebook, and run all cells from this directory. To use another image directory, change IMAGE_DIR in the first code cell; the loader takes this directory as an argument.

Task 1: pixelwise average of ten images; fixed sky ROI; theoretical and measured noise reduction.
Task 2: floating-point convolution with the specified Prewitt kernels; signed derivatives and gradient magnitude.
Task 3: floating-point unsharp masking with sigma=1.0 and amount=2.0; full image and detail comparison.

For submission, use the executed Lab1.ipynb and follow the course submission instructions.
